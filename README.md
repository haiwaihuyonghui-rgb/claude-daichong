## 三种开通方式对比

| 方式 | 怎么做 | 优点 | 缺点 |

## 封号风险与申诉

先说清楚：代充不是官方渠道，账号被封的诱因大多在使用这一侧，不在付款这一侧。常见诱因：

- 在 Anthropic 不支持的地区使用，或频繁切换网络所在国家。
- 多人共用一个账号、多地同时登录。
- 用脚本批量调用网页版，或触发使用政策里的禁止用途。
- 注册时用了虚拟号码、一次性邮箱，或短时间注册多个账号。

降低风险的习惯：网络环境保持稳定、一个账号只给自己用、不要用脚本刷网页版、注册信息真实。

被封了怎么办：登录提示账号被停用时，先看注册邮箱里 Anthropic 的通知邮件，按邮件指引提交申诉；能否恢复、订阅费是否退，以官方处理结果为准。在本店开通的，可以把订单号和停用通知截图发到瑶瑶微信，协助按官方渠道申诉，但封号不在质保范围、不退款。详见 [Claude 封号了怎么办](https://kw.yaoyao.chat/guide/claude-fenghao.html?utm_source=github&utm_medium=readme&utm_campaign=claude-daichong)。
