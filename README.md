## 方法一：官方网页订阅（claude.ai）

- **怎么做：** 登录 claude.ai → 左下角头像 → 设置 → 账单 / 升级 → 选 Pro 或 Max → 填卡付款。
- **价格：** 按上表官方美元价，另加税；用人民币卡付外币可能有银行货币转换费。
- **条件：** 定价页"付款方式"一栏，Pro / Max 写的是信用卡（2026-10-26 核对）。官网没有支付宝、微信付款。
- **优点：** 最正规；Pro 可以年付（折合每月 17 美元）；退款、发票都走官方（[申请退款](https://support.claude.com/en/articles/12386328-request-a-refund-for-a-paid-claude-plan)）。
- **缺点：** 国内发行的卡经常被拒。
- **风险：** 付款风险最低；账号风险主要看使用地区和使用习惯。

## 方法二：苹果 / 谷歌应用内购

- **怎么做：** 在 Claude 的 iOS 或安卓 App 里升级，用应用商店账号的付款方式或余额付款。
- **价格：** 以应用商店显示为准，官方写明手机端价格可能和网页不同（本次没有逐个地区核对 App 内价格）。
- **条件：** 要有能下载 Claude App、并且能付款的应用商店账号；Apple 礼品卡充进账户余额后可以买订阅，但礼品卡不是所有国家或地区都有，有些购买即使用余额付款也可能要求绑定信用卡（[Apple 官方](https://support.apple.com/en-us/118242)，2026-10-26 核对）。
- **优点：** 不用绑信用卡。
- **缺点：** 官方写明 App 内订阅的付款由 App Store / Google Play 处理，付款方式、收据、取消都要在应用商店里管（[Paid plan billing FAQs](https://support.claude.com/en/articles/8325618-paid-plan-billing-faqs)，2026-10-26 核对）。
- **风险：** 网页和 App 各订一份会重复扣费；换地区商店账号步骤多。

## 方法三：礼品卡 / 赠送订阅

- **官方赠送订阅：** Anthropic 帮助中心写明"赠送订阅目前暂停购买，适用于所有账号"，恢复时间未定（[How to gift a Claude subscription](https://support.claude.com/en/articles/12938627-how-to-gift-a-claude-subscription)，2026-10-26 核对）。以前买的礼物在购买后 365 天内到 claude.ai/gift/redeem 兑换。
- **应用商店礼品卡：** 就是方法二用的商店余额，规则见方法二。
- **风险：** 现在如果有人卖"Claude Pro 礼品卡"，先问清楚到底是什么——官方渠道目前买不到。

## 方法四：代充（第三方代付）

- **是什么：** 第三方卖家替你付款，把 Pro / Max 开到**你自己的 Claude 账号**上。原理和要交出什么信息，见 [Claude 代充原理](kaopu-yuanli.md)。
- **价格：** 卖家自己定价，一般比官方美元价折算略高（含代付成本和售后）。远低于官方折算价的要问清为什么，常见是退款单、漏洞单，过几天会被收回。
- **条件：** 一个能正常登录的 Claude 账号；靠谱的做法不要密码、不要验证码。
- **优点：** 支付宝 / 微信就能付；不绑你的卡、不会自动续费。
- **缺点：** 不是官方渠道，**不能找 Anthropic 退款**；只能月付，没有官方年付的折扣。
- **风险：** 卖家不靠谱、索要密码导致账号被盗；封号诱因多在使用这一侧，一般不在代充质保范围。

怎么挑卖家（不管在哪家买）：价格正常、不要密码、到账时间说得清、失败怎么退、掉订阅管不管、售后找得到人。逐项说明见主仓库 [gpt-chongzhi](https://github.com/haiwaihuyonghui-rgb/gpt-chongzhi#怎么判断代充靠不靠谱6-个判断点)。

不建议合租 / 拼车：用量按账号算，多人共用会互相抢额度，多地同时登录容易触发风控，通常也违反服务条款。

## 封号风险与申诉

账号被封的诱因大多在使用这一侧：在不支持的地区使用或频繁切换网络所在国家；多人共用、多地同时登录；用脚本批量调用网页版；注册时用虚拟号码、一次性邮箱或短时间注册多个账号。降低风险：网络稳定、一个账号只自己用、注册信息真实。

被封了：先看注册邮箱里 Anthropic 的通知邮件，按指引申诉；能否恢复、是否退费以官方处理结果为准。详见 [Claude 封号了怎么办](https://kw.yaoyao.chat/guide/claude-fenghao.html?utm_source=github&utm_medium=readme&utm_campaign=claude-daichong)。

## 常见问题

**Q：Claude Pro 官方多少钱？**
A：月付 20 美元/月，年付折合 17 美元/月（一次付 200 美元）；Max 5x 100 美元/月、Max 20x 200 美元/月，都不含税（2026-10-26 核对）。

**Q：App 里订阅和网页订阅价格一样吗？**
A：不一定。官方写明网页价之外，手机端价格可能因应用平台不同而不同。

**Q：能买 Claude 礼品卡吗？**
A：官方赠送订阅目前暂停销售（2026-10-26 核对）。

**Q：代充要给 Claude 账号密码吗？**
A：靠谱的代充不要。本仓库作者的店只要组织 ID。

**Q：代充的会员能找 Anthropic 退款吗？**
A：不能。付款不是你本人完成的，有问题找卖家。介意的请走官方订阅。

**Q：Claude Code 能用吗？**
A：Pro / Max 都包含 Claude Code。国内使用见 [Claude Code 国内使用指南](https://github.com/haiwaihuyonghui-rgb/claude-code-guide-cn)。
